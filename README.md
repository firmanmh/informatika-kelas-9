# 📘 Modul Visual Belajar Mandiri — Informatika SMP Kelas IX (Semester 1)

Modul web interaktif pengganti buku paket sebagai pegangan belajar mandiri siswa SMP Kelas IX dalam mempersiapkan Penilaian Akhir Semester 1.

## Materi yang Dicakup
1. **Bab 1 — Sistem Bilangan & Teknik Perhitungan Unplugged**
   - Simulasi interaktif **Kartu Titik Biner** (klik kartu untuk membuka/menutup bit secara langsung).
   - Langkah pembagian berulang (Desimal ke Biner/Oktal/Heksadesimal) dan tabel bobot perpangkatan.
2. **Bab 2 — Algoritma & Pemrograman Dasar Scratch**
   - Penelusuran rute algoritma pada papan grid 5×5 (*unplugged*).
   - Tampilan antarmuka asli Scratch (`scratch.mit.edu`) beserta 6 kategori balok inti.
3. **Bab 3 — Keamanan Data Pribadi & Anti-Cyberbullying**
   - Ilustrasi animasi waspada jebakan *phishing*, perlindungan kata sandi kuat, autentikasi dua faktor (2FA), dan literasi digital Google *Interland*.
   - Ilustrasi animasi pencegahan *cyberbullying* serta panduan kampanye positif melalui poster Canva dan video pendek.

## Cara Menayangkan Link Online Gratis via GitHub Pages
1. Unggah `index.html` dan `README.md` ke repositori GitHub Anda.
2. Buka tab **Settings** &rarr; pilih menu **Pages** di bilah kiri.
3. Pada bagian **Build and deployment &rarr; Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
4. Tunggu sekitar 1 menit hingga tautan `https://<username>.github.io/<nama-repo>/` muncul dan siap dibagikan ke grup kelas siswa.
