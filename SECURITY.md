# Kebijakan Keamanan (Security Policy)

## Tentang Repositori Ini
Repositori ini berisi **Modul Bacaan Visual & Latihan Interaktif Informatika SMP Kelas IX** berbasis HTML, CSS, dan JavaScript statis yang dihosting melalui **GitHub Pages** sebagai media pembelajaran mandiri siswa.

## Versi yang Didukung
Saat ini, pembaruan keamanan dan perbaikan konten hanya diterapkan pada versi utama yang aktif tayang di halaman utama (`main` branch).

| Versi / Cabang | Status Dukungan |
| :--- | :--- |
| `main` (Versi Aktif) | ✅ Didukung penuh |
| Cabang lama / arsip | ❌ Tidak didukung |

## Privasi & Keamanan Data Siswa
Aplikasi web pembelajaran ini dirancang dengan prinsip **privasi utama (*privacy-first*)**:
- **Tanpa Pengumpulan Data Pribadi:** Situs ini tidak meminta, menyimpan, atau mengirimkan nama lengkap, NISN, alamat email, maupun kata sandi siswa ke server eksternal mana pun.
- **Pemrosesan Lokal (*Client-Side*):** Seluruh interaksi latihan (simulasi kartu biner, kuis konversi bilangan, algoritma robot grid, misi balok Scratch, dan pencocokan benang) berjalan sepenuhnya di peramban (*browser*) perangkat pengguna dan akan ter-reset otomatis saat halaman dimuat ulang.
- **Tanpa Pelacak Pihak Ketiga:** Tidak menggunakan *cookies* pelacakan iklan maupun skrip analitik eksternal yang merekam aktivitas siswa.

## Melaporkan Masalah Keamanan atau Celah Bug
Jika Bapak/Ibu Guru, siswa, atau kontributor menemukan masalah keamanan (misalnya tautan rusak yang mengarah ke situs mencurigakan, celah *Cross-Site Scripting* / XSS, atau gangguan pada skrip latihan), mohon laporkan dengan cara berikut:

1. **Jangan** mempublikasikan celah keamanan secara terbuka di kolom komentar atau *Public Issue* sebelum diperbaiki.
2. Gunakan tab **Security &rarr; Advisories &rarr; Report a vulnerability** pada repositori GitHub ini, atau hubungi pengelola repositori (guru pengampu mata pelajaran Informatika) secara langsung.
3. Sertakan informasi singkat berikut dalam laporan:
   - Bagian bab atau fitur latihan yang bermasalah (contoh: *Latihan Bab 1* atau *Pencocokan Bab 3*).
   - Perangkat dan peramban (*browser*) yang digunakan (contoh: *Chrome di Android* atau *Edge di Windows*).
   - Langkah singkat untuk memunculkan masalah tersebut.

## Waktu Tanggapan
Laporan yang masuk akan ditinjau dan diperbaiki sesegera mungkin agar kegiatan belajar mandiri siswa tetap aman dan lancar.
